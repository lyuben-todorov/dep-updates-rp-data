# dep-updates-rp-data

Canonical v0.0.4 dependency-update entries for the [RP 2025/2026 Cargo sub-question](https://github.com/lyuben-todorov/dep-updates-rp).

Each `cargo-*.json` is a single reproduced dependency-update PR, schema-validated against `schema/entry.schema.json` in the main repo. See `docs/db-design.md` in the main repo for layering and the reproduction model.

This repo is included in the main repo as a submodule at `dep-updates-poc/data/cargo/`.
